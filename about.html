Sobre o site

O Trilhas PR é um guia fictício de trilhas do Paraná, criado para a Atividade Somativa 1. O objetivo é mostrar, só com HTML, CSS e JavaScript puros (sem frameworks), um site com visual padronizado, menu comum, formulário validado e leitura de dados enviados pelo método GET.

As informações das trilhas são aproximadas e servem apenas como conteúdo de exemplo.

Organização dos arquivos

index.htmlPágina inicial com cards e janela pop-up "Saiba mais".
form.htmlFormulário de inscrição enviado com método GET.
formAction.htmlRecebe os dados do formulário e os mostra numa tabela.
about.htmlEsta página: apresentação do trabalho e do autor.

script/formAction.jsLê a URL com URLSearchParams e monta a tabela de confirmação.
script/about.jsAbre e fecha os painéis do acordeão abaixo.
img/Logo e ilustrações em SVG feitas para o site.

Como cada tecnologia foi usada

Elementos semânticos (header, nav, main, section, article, footer), formulário com tipos de campo (email, tel, date, radio, checkbox) e atributos de validação (required, minlength, maxlength, pattern). Todos os links e arquivos usam caminho relativo.

Cores guardadas em variáveis (:root), classes reaproveitadas em várias páginas (.caixa, .btn, .titulo, .etiqueta), layout com Flexbox e Grid, animação do modal com @keyframes e @media para adaptar o menu ao celular.

Eventos de clique (menu, tema, modal, acordeão), validação com expressões regulares, máscara de celular, contador de caracteres, leitura dos parâmetros GET com URLSearchParams e alteração de estilo trocando classes com classList.
